# Manrope

Manrope de Mikhail Sharanda, archivo variable WOFF2, pesos 200–800, subconjunto latino (incluye español). Descargado el 20/11/2026 de Google Fonts y servido localmente con `next/font/local`; no se consulta Google durante el build ni al navegar.

- Fuente: https://fonts.gstatic.com/s/manrope/v23/xn7gYHE41ni1AdIRggexSg.woff2
- Hoja de origen: https://fonts.googleapis.com/css2?family=Manrope:wght@200..800&display=swap (respuesta para navegador moderno).
- Licencia SIL Open Font License 1.1: `OFL.txt`, conservada desde https://github.com/google/fonts/tree/main/ofl/manrope.
- Tamaño del archivo: 24.532 bytes.

La variable CSS `--font-manrope` incluye el fallback ajustado por Next.js. Se precarga una sola fuente; `font-display: swap` permite mostrar texto mientras llega el archivo.
